Справка — ai-coder

← к панели Все отчёты Статистика

Краткая справка по режимам, опциям и типовым сценариям запуска агента ai-coder.

Режимы

Режим Флаг Что делает
plain — (по умолчанию) Один запрос к LLM: без доступа к файлам и инструментам. Быстро и дёшево — для вопросов, планов и генерации текста.
tool-loop --tool-loop Цикл «мысль → вызов инструмента → результат». Агент читает файлы, правит их, запускает проверки. Основной рабочий режим.
decompose --decompose Разбивает цель на подзадачи и выполняет их последовательно. Удобно для крупных многошаговых задач.
plan --plan Только строит план работ без изменений в коде. Полезно перед запуском основного агента.
chain --chain Цепочка шагов из плана: каждый пункт плана выполняется отдельным проходом.
split-goals --split-goals Разбивает одну общую цель на несколько независимых целей и обрабатывает их по отдельности.

Опции

Опция Описание
--apply Применить предложенные агентом изменения к файлам проекта.
--commit Закоммитить изменения в git после успешного применения (обычно вместе с --apply).
--dry-run Сухой прогон: ничего реально не пишется и не запускается, только журнал действий.
--dry-read Чтение разрешено, запись и выполнение команд блокируются. Безопасный анализ кода.
--max-cost-rub Ограничение стоимости запуска в рублях. Агент остановится при превышении лимита.
--max-iterations Максимальное число итераций цикла агента. Защита от зацикливания.
--auto-fix-issues Автоматически исправлять найденные проблемы (по результатам проверок).
--with-tests Запускать тесты после изменений и учитывать их результат.
--issue Работа по конкретной issue: агент учитывает её описание как цель.
--plan Режим построения плана (см. «Режимы»).

Действия (run)

Действие Режим Что делает
greet read Познакомиться с проектом: стек, структура, точки входа.
inventory read Список функций, классов, переменных.
explain read Объяснить файл, функцию или класс.
suggest_improvements read Ревью: баги, безопасность, архитектура.
write_readme write Сгенерировать README.md.
add_docstrings write Дописать докстринги.
refactor write Предложить рефакторинг.

Список с оценками стоимости: ai-coder actions --verbose

Примеры run-команд

Разовые действия без агента. Открой панель, выбери «Тип задачи → run», действие и путь — или нажми «→ в форму».

ai-coder run greet .
ai-coder run inventory . --depth normal
ai-coder run explain . --only-path ai_coder/agent.py
ai-coder run suggest_improvements . --depth deep
ai-coder run write_readme . --apply

Рекомендации

  • Начинайте с --plan или --dry-read, чтобы оценить объём работ и стоимость до правок.
  • Всегда задавайте --max-cost-rub на незнакомых задачах — это ограничивает расход.
  • Для мелких однозначных правок достаточно tool-loop без лишних опций.
  • Перед --commit убедитесь, что рабочее дерево чистое и вы готовы принять изменения.
  • Комбинируйте --apply --with-tests, чтобы правки проверялись тестами автоматически.
  • Крупные задачи дробите через decompose или split-goals — так проще контролировать прогресс.

Примеры

Первый запуск (безопасно, ничего не меняет):

# 1. Список действий (0 RUB, без API)
ai-coder actions --verbose
# 2. Обзор проекта (~0.05 RUB, ничего не меняет)
ai-coder run greet . --depth normal
# 3. Найти что-то в проекте (read-only, write блокируется)
ai-coder agent "Найди все TODO в проекте" . --tool-loop --dry-read

План работ без изменений в коде:

ai-coder agent "Добавить ретраи в llm.py" . --plan

Безопасный анализ с ограничением стоимости:

ai-coder agent "Найти неиспользуемый код" ai_coder/ --dry-read --max-cost-rub 0.5

Правка с проверкой тестами:

ai-coder agent "Поправить парсинг дат" ai_coder/ --tool-loop --apply --with-tests

Применить и закоммитить:

ai-coder agent "Обновить README" . --tool-loop --apply --commit

Крупная задача через декомпозицию:

ai-coder agent "Перевести проект на новый API" . --decompose --max-cost-rub 5
