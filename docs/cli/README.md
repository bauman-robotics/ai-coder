## Обзор

| команда | назначение |
|---------|------------|
| actions | Показать доступные действия из конфига. |
| run | Выполнить действие над проектом. |
| agent | Запустить агента: LLM строит план шагов и выполняет их по цели. |
| fix | Автоматическое исправление: verify → fix → verify → ... |
| usage | Показать сводку расходов с фильтрами. |
| backups | Список бэкапов проекта. |
| rollback | Откатить изменения проекта из указанного бэкапа. |
